# Executed public-provider dumps

These are actual bounded discovery runs, not an exhaustive or verified product database. See the final summary line in each JSONL for scope/counts. Wikidata structured records are CC0; linked images retain individual licenses and are not bundled merely because their URLs appear. PubMed dumps contain bibliographic metadata and reference links, not licensed full-paper reproductions. Queue entries require manual identity and scientific review. Private observations, reviews, accounts and SQL backups are excluded.
